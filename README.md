# Cálculos y simulaciones
Este repositorio reúne cálculos, simulaciones y material de tesis realizados durante mi pregrado en física. La organización busca separar: (1) notebooks de estudio y exploración, (2) scripts y tablas para modelos físicos, y (3) la documentación formal en LaTeX.

## Estructura general
- Astrophysics: notebooks sobre relatividad, ondas gravitacionales y órbitas. Ver [Astrophysics/README.md](Astrophysics/README.md).
- Libro_Trabajo_de_Grado: proyecto de tesis en LaTeX con capítulos y bibliografía. Ver [Libro_Trabajo_de_Grado/README.md](Libro_Trabajo_de_Grado/README.md).
- NS_Structure: modelos de materia de estrella de neutrones, EoS y solución TOV, con datos y resultados. Ver [NS_Structure/README.md](NS_Structure/README.md).
