# Astrophysics
Esta carpeta contiene notebooks de temas de astrofísica relativista y ondas gravitacionales. Son cuadernos de trabajo con cálculos, gráficos y análisis exploratorios.

## Notebooks
- [chandraseckhar_model.ipynb](chandraseckhar_model.ipynb): modelo de Chandrasekhar y límites degenerados.
- [gw170817_mass_estimate.ipynb](gw170817_mass_estimate.ipynb): estimación de masas asociadas al evento GW170817.
- [linear_grav_waves.ipynb](linear_grav_waves.ipynb): ondas gravitacionales en aproximación lineal.
- [orbitas_schwarszchild.ipynb](orbitas_schwarszchild.ipynb): órbitas en el espacio-tiempo de Schwarzschild.

## Uso sugerido
Abrir cada notebook y ejecutar las celdas en orden para reproducir figuras y resultados.
